# 审批设计检查清单

## 范围与归属

- [ ] 说明业务目标、审批对象、发起条件和完成条件
- [ ] 每项必填或条件必填信息均写明为什么需要与如何提供
- [ ] 缺失信息标注确认人、截止时间及是否阻塞
- [ ] 明确业务表单类或自定义表单类；记录表单、流程流转模型和版本
- [ ] 业务表单类已登记业务线、摘要、领导审批结束、账单生成、特殊条件字段、适用范围、可确认字段、审批详情页展示字段及 Web、APP、H5 配置
- [ ] 领导审批结束和账单生成均已按业务表单明确标记“有”或“无”；两项仅作为已封装监听器的配置确认，不在需求中设计监听器或节点
- [ ] 业务校验开关、关联校验和提交失败处理的研发实现已确认
- [ ] 新增业务表单审批时，研发已在所属业务线的业务校验中补充该表单；业务校验仅承担流程关联，不包含节点配置
- [ ] 需求已在[在线登记表](https://www.kdocs.cn/l/co5Ah0IILUqN)中登记
- [ ] 原型已贴上在线登记表截图和《审批流程需求交付表》；触发按钮和跳转页面截图可按需补充
- [ ] 逐项映射已发布能力，并引用可验证的能力证据
- [ ] 将能力缺口分类为通用模块候选迭代或业务系统实现
- [ ] 未把候选能力写成已支持或承诺上线

## 流程完整性

- [ ] 字段字典覆盖字段标识、类型、值域、来源、取值时点、敏感性、快照方式和用途
- [ ] 标题与摘要规则包含字段顺序、格式化、空值替代和脱敏
- [ ] 分支字段已核验可用性，分支条件说明数据来源、计算时点、运算符、优先级、空值处理和默认路径
- [ ] 多人处理的业务语义明确，且未提前映射为具体节点类型
- [ ] 驳回、退回、撤回、撤销、终止和重新提交的业务规则明确
- [ ] 未要求或输出流程图、节点设计表、节点标识、连线或节点参数

## 参与人和权限

- [ ] 每个审批节点都有参与人规则和解析时点
- [ ] 覆盖无人、多人、离职、兼职和组织变更情况
- [ ] 未硬编码个人作为长期生产规则
- [ ] 服务端校验任务操作权限和实例当前状态
- [ ] 敏感字段按节点和角色设置查看、编辑或脱敏权限
- [ ] 代理、委托和转交保留原责任关系与审计记录

## 状态和版本

- [ ] 区分流程实例、审批任务和业务单据状态
- [ ] 每个操作写明前置状态、目标状态和失败恢复
- [ ] 已发布定义通过新版本变更
- [ ] 在途实例继续绑定原版本，或提供明确迁移方案
- [ ] 审批完成与业务处理成功分别记录
- [ ] 表单、流程流转模型和业务流程定义的版本关系可追溯

## 数据和集成

- [ ] 区分业务主数据、审批快照和实时引用数据
- [ ] 发起请求包含业务唯一标识与幂等控制
- [ ] 任务操作防止重复点击和并发冲突
- [ ] 回调或事件包含唯一标识，并由消费方去重
- [ ] 定义超时、重试、死信或人工补偿机制
- [ ] 定义鉴权、组织隔离、敏感数据保护和日志脱敏
- [ ] 能通过查询或对账恢复丢失的通知与回调
- [ ] 必审开启时，未关联流程、模型未发布或表单标识不匹配均会阻断业务提交

## 通知审计与运维

- [ ] 通知失败不破坏流程状态，且有补发或查询方式
- [ ] 审计记录包含定义版本、节点、操作者、动作、意见、时间和结果
- [ ] 管理员干预经过授权、说明原因并完整留痕
- [ ] 可按流程实例标识、业务标识和任务标识定位问题
- [ ] 监控覆盖失败率、积压、超时、回调和参与人解析异常

## 上线验收

- [ ] 典型路径、全部分支和边界值均有测试用例
- [ ] 权限、并发、重复请求、超时和异常恢复经过验证
- [ ] 新旧定义版本和在途实例兼容性经过验证
- [ ] 能力归属、接口契约、上线范围和责任人已确认
- [ ] 发布、回滚、补偿和问题响应方案可执行
